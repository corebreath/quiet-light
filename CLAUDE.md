## What is this project?

A children's inner-world journey app for ages 8–12. Expo SDK 56 + expo-router, no backend.
Core message: **"I am safe inside myself."**

## How to run the app

```bash
cd app
npx expo start
```

Scan QR with Expo Go (Android). Press `a` for emulator.
